# 迁移

[← 返回首页](../README.md) · [安装](安装.md) · [使用](使用.md)

换电脑时，需要分别准备**插件代码、图片和个人设置**。只重新克隆仓库不会带回收藏、图单和当前背景。

## 需要搬哪些东西

| 内容 | 原来的位置 | 新电脑上怎么恢复 |
| --- | --- | --- |
| 插件代码 | 安装时的插件目录 | 重新下载并安装 |
| 已发布图库 | 插件目录的 `wallpapers` | 复制原图，或重新下载，完整约 9.06 GiB |
| 自备图片 | 图库中「管理壁纸文件」显示的目录 | 复制分类文件夹，保留文件名与目录结构 |
| 收藏、图单、构图、外观与轮播设置 | DSH 数据目录的 `dsh-bg-atelier/settings.json` | 使用下方导出与导入命令 |
| WE 场景属性与预设 | 同一数据目录的 `we-scene-properties.json` | 如需保留，另行备份此文件；WE 壁纸本身由 WE 管理 |

## 1. 在旧电脑导出设置

在插件仓库根目录运行，输出位置可以自行修改：

```powershell
node tools/settings.mjs export --out 'D:\bga-settings.json'
```

同时备份自己的图片。导出的 JSON **不包含图片**。如果使用了 WE 场景预设，另行备份 `we-scene-properties.json`。

## 2. 在新电脑安装并准备图片

按[安装教程](安装.md)安装插件，然后把图片复制到新电脑的放图目录，或下载已发布图库。保留分类和文件名，才能让原有图单找到图片。

WE 订阅、本地项目以及原生桌面桥也需要在新电脑上分别准备，见[动态壁纸](动态壁纸.md)。

## 3. 导入设置

在新电脑的插件仓库根目录运行。先预览，再确认写入：

```powershell
node tools/settings.mjs import 'D:\bga-settings.json'
node tools/settings.mjs import 'D:\bga-settings.json' --yes
```

第一条命令仅预览；第二条写入前会自动备份原设置为 `settings.json.bak-*`。导入会检查字段并修正超出范围的数值，图片缺失时会提示。

导入完成后完全重启 DSH Desktop，检查当前背景、收藏、图单和构图。需要查看当前配置时，可以运行 `node tools/settings.mjs show`。

## 宿主升级后插件未加载

部分旧版 DSH Desktop 在启动迁移时可能无法正确处理 `link:` 的绝对路径。典型日志为 `migration deferred`、`could not stage`，或 `profiles/web/.generations-deferred.json` 反复出现。

先核对插件路径仍然存在，并检查 DSH 的版本与插件安装状态。旧版曾使用过的 `KEEP_IN_SHARED_TREE` 本地补丁属于 DSH 应用本身，不随本仓库迁移，宿主升级也可能覆盖它；不要把旧电脑的补丁当成插件安装的一部分。

WE 桌面桥同样安装在 DSH 应用中，升级后如提示桥未加载，需要按[原生桥说明](../we/native/README.md)重新安装并完全重启 DSH Desktop。

# 安装

[← 返回首页](../README.md) · [下一步：使用](使用.md)

底图工坊安装在 DSH Desktop 的 `web` 配置中，之后随 DSH 启动加载，也可以在 **设置 → 插件** 中管理。

## 安装前准备

- 已安装 DSH Desktop，终端能运行 `dsh`。
- 用 Git 下载源码；没有 Git，也可以使用 GitHub 的 **Code → Download ZIP**。
- Wallpaper Engine 是可选功能，使用普通图片背景不需要它。

## 安装步骤

### 1. 下载源码

在 PowerShell 中运行，路径可以按自己的习惯修改：

```powershell
$pluginDir = 'D:\DeepSeek\dsh-plugins\dsh-desktop-wallpaper'
New-Item -ItemType Directory -Force (Split-Path $pluginDir) | Out-Null
git clone https://github.com/Raylen-berry/dsh-desktop-wallpaper.git $pluginDir
```

如果使用 ZIP，请先解压，然后把 `$pluginDir` 设为**包含 `package.json` 的那一层目录**。ZIP 解压后的目录名通常带有 `-main`：

```powershell
$pluginDir = 'D:\DeepSeek\dsh-plugins\dsh-desktop-wallpaper-main'
```

### 2. 添加插件

```powershell
dsh plugin --profile web add "link:$pluginDir"
```

`link:` 会引用这个本地目录，安装后请保留目录。

### 3. 重启并检查入口

等正在执行的任务结束，**完全退出并重新打开 DSH Desktop**。仅刷新页面不能保证安装生效。

重启后确认：

- **设置 → 底图工坊** 可以打开。
- 侧边栏底部出现「流光宝珠」换图按钮。
- **设置 → 插件** 中能找到 `dsh-bg-atelier`。

### 4. 准备背景图片

进入 **底图工坊 → 图库 → 管理壁纸文件**，查看放图目录。放入自己的图片后点「刷新图库」，或点击「下载内置壁纸」取得已发布图库。

仓库不包含图片。当前发布清单是 313 张原图，完整下载约 9.06 GiB；也可以只用自己准备的图片。下载中断后再次点击即可继续补齐，已经校验通过的图片会跳过。

如果希望在终端下载，在插件根目录执行：

```powershell
Set-Location $pluginDir
node tools/fetch-wallpapers.mjs
```

图片目录与格式见[使用指南](使用.md)。

## 升级

### 使用上面的 Git + link 安装方式

在**没有自行修改源码**的情况下，更新本地目录，再重启 DSH Desktop：

```powershell
Set-Location $pluginDir
git pull --ff-only
```

若提示本地改动或分支分歧，请先保留并处理自己的修改。ZIP 安装则重新下载源码，用新解压目录重新执行添加命令；自备图片和个人设置请先备份，见[迁移](迁移.md)。

### 使用 DSH 管理的安装方式

```powershell
dsh plugin --profile web update dsh-bg-atelier
```

更新后完全重启 DSH Desktop。使用 WE 实时场景时，如果更新涉及桌面桥，还需按[桥安装说明](../we/native/README.md)重新安装桥。

## 停用与卸载

临时停用：在 **设置 → 插件** 中关闭插件，并重启 DSH Desktop。

卸载：

```powershell
dsh plugin --profile web remove dsh-bg-atelier
```

卸载后重启。需要保留个人图片和配置时，提前按[迁移教程](迁移.md)备份。

## 安装后找不到入口

1. 确认安装命令成功，且添加到了 `web` 配置。
2. 确认路径指向包含 `package.json` 的目录，目录仍然存在。
3. 确认已完全退出并重新启动 DSH Desktop。
4. 如果启动日志出现 `migration deferred` 或 `could not stage`，见[迁移中的宿主兼容说明](迁移.md#宿主升级后插件未加载)。

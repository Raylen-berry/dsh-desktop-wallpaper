# 动态壁纸

[← 返回首页](../README.md) · [安装](安装.md) · [使用](使用.md)

本插件读取本机 Wallpaper Engine（WE）的订阅与本地项目。先安装 WE 并准备壁纸，再打开 **设置 → 底图工坊 → 动态壁纸 → Wallpaper Engine 库**。

## 先选合适的模式

| 模式 | 适合什么情况 | 需要什么 |
| --- | --- | --- |
| 场景：静态近似 | 用场景中的一幅静态画面作背景 | 本机有 WE 场景文件，不要求 WE 正在运行 |
| 场景：实时 + 鼠标跟随 | 保留场景动画与自带的鼠标视差 | Windows、运行中的 WE，以及已安装的原生桌面桥 |
| 视频壁纸 | 在背景循环播放本机视频 | 本机 WE 壁纸库中的视频文件 |
| 网页壁纸 | 把网页项目用作背景 | 本机网页项目；不保证 WE 专有网页功能兼容 |

实时场景需要额外配置，并会增加资源消耗。先使用静态模式即可熟悉图库。

## 启用实时场景

1. 按[原生桥安装与回退说明](../we/native/README.md)构建并安装桌面桥。桥会修改 DSH 应用入口，请保留安装备份。
2. 等当前任务结束，完全退出并重启 DSH Desktop，同时确认 WE 已运行。
3. 在 WE 库选中场景，再切换到「实时 + 鼠标跟随」。连接失败时会显示原因并保留静态画面。
4. 更新 DSH 或涉及桥的插件版本后，如桥未加载，重新安装桥并完全重启。

实时模式保留壁纸本身支持的鼠标效果；点击、拖动和键盘不会透传给壁纸。

## 使用与已知限制

可按名称、标签或编号搜索，并按场景、视频、网页筛选；筛选不会更换当前背景。当前背景区可切换实时/静态模式或手动重新连接。

v1.9.0 增加场景属性面板：音量、播放倍率、鼠标视差、翻转、主题配色，以及从壁纸读取的人物、背景、音频等分组。滑块只修改草稿，点击「应用到此背景」才一次性发送；支持放弃未应用修改、按壁纸保存和加载预设及恢复默认，独立保存在 DSH 配置目录 `we-scene-properties.json`。不修改订阅文件，不把更改应用到 Windows 桌面壁纸。自定义图片等文件属性暂不提供导入；属性里的条件和脚本不会执行。

实时采集提供 30 / 45 / 60 帧目标，默认「均衡」45；显示实际出帧和尺寸。保留原尺寸、原鼠标对齐，不强制缩小采集图像：本机同场景缩放会使帧率降到 11–13，原尺寸 30 帧档约 28.4，45 / 60 帧档约 35，45 档的最长帧间隔更短。帧率取决于机器负载和场景，不能保证稳定 60。视频播放后隐藏后备图，状态更新不再重建主题样式；原生窗口仅变更层级时不重复触发尺寸调整。

从旧版升级需重装原生桥并完整退出、重启 DSH，加载新增属性接口。没有修改 WE 全局画质。

v1.8.1 修复正式桌面权限导致实时场景退回静态图的问题；从 v1.8.0 升级需要重新运行原生桥安装器并完全退出、重启 DSH Desktop。页面内部导航现在保留实时连接，连接失败会留下可查错误。

在「底图工坊 → Wallpaper Engine 库」选择壁纸。场景新增两种模式：

- **实时 + 鼠标跟随**：WE 原引擎运行场景，原生桥把专用窗口画面接入 DSH。保留场景自身的动画和鼠标位置驱动效果，默认 45 fps 目标、可选 30 / 60；需要 WE 已运行，以及已安装并重启生效的桌面桥。
- **静态近似**：保留 v1.7.1 的有界工作线程合成，不需要 WE 运行。实时连接失败时也保留静态画面并显示原因。

实时模式只读取鼠标位置，不转发聊天中的点击和键盘。窗口移动、缩放时跟随；最小化/隐藏释放实时场景，恢复时重连；清除背景、切换壁纸和卸载客户端时停止视频轨道与专用窗口。选择壁纸不改变手动配色，「采用壁纸配色」才会保存明确选择。

原生桥需要 Windows。安装、源代码构建、权限范围、更新后的重装及回退见 [原生桥说明](../we/native/README.md)。**新增桌面桥后必须完全重启 DSH Desktop，仅刷新页面或重启 Harness 不够。** DSH 更新可能覆盖入口；插件会提示桥未加载并退回静态模式。

## 库和媒体

支持 workshop 订阅以及 projects/<项目>、projects/<组>/<项目> 本地结构；本地 ID 取相对路径哈希，跳过目录链接，不遍历项目素材目录。图库和媒体共享 60 秒扫描缓存，手动刷新强制重新发现。

WE 状态取进程信息，端口只作诊断。订阅和本地项目均可通过官方 CLI「在 WE 打开」。视频静音循环播放并支持 Range；web 仍为不可点击的沙箱背景，不保证 WE 专有网页 API 兼容。

静态合成仍支持部分 PKG/TEX/LZ4/DXT/PNG，采用单工作线程、八项等待队列、45 秒超时、一分钟失败冷却和尺寸/字节限制。它不完整渲染 scene 动画和特效；实时模式才使用 WE 引擎。旧静态缓存继续兼容，尚未增加源场景改变后的自动失效。

## 历史验证（2026-09-24）

- 18 项语法检查、10 套离线测试通过；新增原生接口边界、安装器幂等性、客户端取消/迟到流/隐藏恢复清理测试。
- 本机库扫描：22 项，21 个本地项目（含 WE 内置项目）、1 个订阅。
- 完整 DSH 页面最后 10 秒实测约 30.9 fps（原基线约 28.4），309 帧、报告丢帧 0；独立实例约 35 fps 不代表完整页面性能。曾遇到一次原生窗口关闭，最后复查未再出现，原因尚未确定；短时采样不是长期稳定性保证。
- 正式插件客户端集成：初次播放 984×660，窗口缩放后 1134×710，最小化恢复建立新流，画面继续更新；输入框命中和清除断言通过。
- 原生鼠标坐标通过专用 SceneScript 夹具核对。壁纸必须自身支持相应鼠标效果；点击、拖动和键盘交互不会透传到壁纸。
- 实时模式会额外运行一份场景，性能高于静态图的消耗；多屏跨 DPI、长期稳定性和 4K 压力尚未完整验收。场景声音通过属性面板控制，默认静音。

本地素材不随插件发布；个人配色与当前底图设置不由安装器重置。v1.7.1 已经覆盖前的配色没有历史记录，无法自动恢复。

# 使用

[← 返回首页](../README.md) · [安装](安装.md) · [动态壁纸](动态壁纸.md)

打开 **DSH Desktop → 设置 → 底图工坊**。上方显示当前图片和快捷按钮，下方有四个页签：

| 页签 | 在这里做什么 |
| --- | --- |
| 图库 | 找图片、收藏、整理图单、管理图片文件 |
| 外观 | 调整当前图片构图、明暗、配色、输入框样式和特效 |
| 切换 | 设置轮播间隔与渐变效果 |
| 动态壁纸 | 扫描并使用本机 Wallpaper Engine 壁纸 |

## 放入自己的图片

在 **图库 → 管理壁纸文件** 查看放图目录，在目录下建立分类文件夹，再放入图片：

```text
wallpapers/
├── 风景/
│   ├── 山间.png
│   └── 海边.jpg
└── 插画/
    └── 夜色.webp
```

回到图库点「刷新图库」，新图片就会出现，不必为加图重启 DSH。

支持 PNG、JPG/JPEG、WebP、GIF、SVG、AVIF、BMP。根目录的散图归入「未分类」。图片文件名末尾带 `_高清`、`_4K`、`_HD` 等标记时，会显示「高清」角标，可按清晰度筛选。

### 有多个图片目录时

插件按下表顺序，使用**第一个有受支持图片的目录**，不会把所有目录合并成一个图库：

| 优先级 | 目录 |
| --- | --- |
| 1 | 环境变量 `DSH_BG_ATELIER_WALLPAPERS` 指定的绝对路径 |
| 2 | DSH 数据目录下的 `dsh-bg-atelier/wallpapers`，推荐存放个人图片 |
| 3 | 插件目录下的 `wallpapers`，下载已发布图库时使用 |
| 4 | 工作区中的 `dsh-plugins/dsh-desktop-wallpaper/wallpapers`，兼容旧版 |

以「管理壁纸文件」显示的当前目录为准。若自己的图片和下载图库分在两处，当前命中的目录可能只显示其中一组；可以把要一起浏览的图片整理到同一个目录。

## 收藏与图单

**图单就是一组自己挑选的图片。** 同一张图可以属于多个图单。

1. 点击图片，设为当前背景。
2. 点「♡ 喜欢」，把它放进「我喜欢」。
3. 用「我的图单」旁的加号新建图单，或用图片上的加号加入已有图单。
4. 需要批量整理时，开启多选，再批量加入或移出。
5. 在图单中点「调整顺序」，拖动卡片手柄；也能用左右按钮，或聚焦手柄后按 `Alt + 左/右方向键`。

删除图单或移出图片只改变收录关系，不会删除原图。最近使用保留最近 36 张图片。

## 换图与轮播

上方的「上一张」「换一张」「开始轮播」，以及侧边栏宝珠，都按当前**切换范围**选图。

- 先在顶部选择图单或文件夹，或进入某个图单后点「设为切换范围」。
- **随机**：按轮次洗牌，同轮内不重复；**顺序**：按图单或文件夹的排列循环。
- 「上一张」沿本次打开页面后的选择记录返回；随后「换一张」可沿记录前进。
- 自动轮播默认关闭，间隔可选 1–120 分钟。窗口失焦、隐藏或冻结时暂停；回到前台重新计算完整间隔。
- 在「切换」中调整渐变时长和开始前的等待时间。快速连续点击时，画面会追上最后一次选择。

**浏览其它图单或搜索不会改变切换范围。** 空图单不会自动改成全图库；删除当前切换图单会暂停轮播。暂时缺失的文件会被跳过。

## 外观与构图

| 设置 | 效果 |
| --- | --- |
| 这张壁纸的构图 | 九宫格焦点与 1–2.2 倍缩放，每张图片独立记住 |
| 背景明暗与透光 | 调整背景和界面的视觉层次 |
| 配色 | 十套预设，也可自定义主色与深色 |
| 输入框卡面 | 调整透明度、模糊和阴影 |
| 输入框特效 | 流萤、气泡、光带扫过、星轨环绕、浮尘光斑、落樱、墨韵涟漪、雨丝，或关闭 |

输入框特效在未选择底图时也可以使用。对话宽度与消息气泡样式由 [会话策略插件](https://github.com/Raylen-berry/dsh-cache-control) 管理。

## 设置保存

页面上方显示保存状态，设置会自动写入本机 DSH 数据目录的 `dsh-bg-atelier/settings.json`。看到「保存失败」时，点击「重试保存」。

收藏、图单、播放顺序、构图与外观可随设置导出；图片需要另外复制或下载，见[迁移](迁移.md)。

## 常见问题

| 遇到的情况 | 先检查什么 |
| --- | --- |
| 装好了但没有背景 | 仓库只有代码；先准备图片，再在图库选一张 |
| 新放的图片没出现 | 放图目录是否与界面显示一致，格式是否支持；点「刷新图库」 |
| 只能看到自备图片，看不到下载图库 | 多个目录不会合并；核对上面的目录优先级 |
| 下载中断或失败 | 确认网络可访问 GitHub Release，随后重试；已校验图片会跳过 |
| 轮播停了 | 窗口是否在后台，范围是否为空，是否正在使用动态壁纸 |
| 切大图稍有停顿 | 原图保持原尺寸，解码与显存占用随图片大小增加；可换用较小的自备图片 |
| WE 实时场景退回静态图 | 检查 WE 是否运行、桌面桥是否已安装，以及是否完整重启 DSH；见[动态壁纸](动态壁纸.md) |
